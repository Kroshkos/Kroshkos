## ❄️ Обо мне

**Снежок** — fullstack-разработчик, который строит модульные платформы полного цикла:
от async-бэкенда на **FastAPI** и плагинной архитектуры до **React / React Native** и Telegram-ботов.
Люблю задачи, где система переживает рост требований: полиморфные сущности, динамические реестры модулей,
ролевые модели, Transactional Outbox вместо «костылей». Пишу так, чтобы ядро ничего не знало о модулях.

```text
$ whoami
> Kroshkos — Python ✦ TypeScript ✦ Docker ✦ PostgreSQL/SQLite ✦ Telegram API
> девиз: «лучшая архитектура — та, которую можно не трогать при добавлении фичи»
```
